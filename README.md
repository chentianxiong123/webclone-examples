# webclone-examples

Examples for [webclone-skill](https://github.com/chentianxiong123/webclone-skill).

Each directory is a complete clone project — original snapshot, extracted assets, and final rebuild — so you can trace the full pipeline.

## Projects

- **baidu-translate/** — Baidu Translate (`fanyi.baidu.com`) — snapshot + component extraction, 11 blocks extracted
- **bilibili/** — Bilibili homepage — 3-layer pipeline (snapshot → extract → Go+HTMX rebuild)
